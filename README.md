# وطن يسكن القلوب 🇸🇦
تطبيق ويب عربي تفاعلي للاحتفاء باليوم الوطني السعودي.

الجهة: الابتدائية والمتوسطة الأولى بصخيبرة – قطاع الحناكية  
الإشراف: رائدة نشاط المرحلة الابتدائية – أ. أفنان الطلحي

## رفعه إلى GitHub
ارفع الملفات الموجودة داخل هذا المجلد إلى جذر مستودع `watan`.

## ملاحظة
النسخة الحالية تحفظ المشاركات على نفس الجهاز باستخدام localStorage. مشاركة الرسائل بين جميع الزوار تحتاج قاعدة بيانات لاحقًا.
